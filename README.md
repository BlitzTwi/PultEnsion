# PultEnsion — website

The public pages for **PultEnsion**, a Chrome extension that turns a whole group
of extensions off with one click.

- `index.html` — what the extension does
- `privacy.html` — privacy policy (this is the URL the Chrome Web Store needs)
- `terms.html` — terms of use

Plain HTML and one stylesheet. No build step, no JavaScript, no third-party
requests. Served with GitHub Pages: **Settings → Pages → Deploy from a branch →
`main` / `(root)`**.
